Plugin Manager

Install, update, activate and delete ResourceSpace plugins in the browser – no server access needed.

Plugin Manager lets administrators manage plugins without logging in to the server. Upload a plugin as a .zip archive (also to update an existing one), activate or deactivate it, open its options or delete its folder.

Features

Upload a .zip

The archive is checked and unpacked into the plugins folder. Both layouts work: a top folder with the plugin, or the plugin files directly in the archive.

Overwrite with confirmation

When the plugin already exists, the installed and uploaded title and version are shown side by side – Overwrite or Cancel.

Safe unpacking

Limits on file count and size, no paths leaving the plugin folder, no symbolic links, system junk skipped. Unpacked to a temporary folder first, and the old version is restored if anything fails.

Installed plugins

One table of plugins from plugins/ and filestore/plugins: title, version, description, status, options and Activate / Deactivate.

Delete a plugin

Only inactive plugins, confirmed by typing the plugin name. The folder is moved first and deleted afterwards, so a failed delete never leaves half a plugin.

Clear reasons

Plugins enabled in config.php, blocked by $disabled_plugins or without a YAML file are shown with the reason why they cannot be changed.

Installation

In ResourceSpace

  1. Plugin Manager cannot install itself – do the first installation from the command line.
  2. Activate it in System > Plugins and open its Options.
  3. Later updates: Upload a plugin > choose the new .zip > Overwrite.

Updating: upload the new .zip and choose Overwrite. Settings and data are kept in the filestore, outside the plugin folder.

On the server (command line)

# download and unpack – <RS_ROOT> is your ResourceSpace folder
cd /tmp
curl -fLO https://github.com/s29829/plugin_manager/releases/download/v1.15/plugin_manager-1.15.zip
# only when updating – the plugin data stays in the filestore
sudo rm -rf <RS_ROOT>/plugins/plugin_manager
sudo unzip -q plugin_manager-1.15.zip -d <RS_ROOT>/plugins/
sudo chown -R www-data:www-data <RS_ROOT>/plugins/plugin_manager

www-data is the user that runs PHP (Apache on the RHEL family: apache). Then activate the plugin in System > Plugins. With git: git clone https://github.com/s29829/plugin_manager <RS_ROOT>/plugins/plugin_manager

Requirements

  • ResourceSpace 11
  • PHP zip extension
  • Write access of the web server user to the plugins folder
  • Plugin Manager cannot install itself – install it the first time from the command line
